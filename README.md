# SQE Lab 03 - Interacting with Form Elements

This lab focuses on interacting with web forms using Selenium WebDriver and Python.

## Requirements
- Python 3
- Google Chrome
- Selenium WebDriver

## Exercises
1. Fill out a registration form using Selenium.
2. Verify checkbox states before and after clicking.
3. Select and verify radio button options.
4. Select dropdown options using text, index, and value.

## Topics Covered
- send_keys()
- click()
- clear()
- is_selected()
- Select Class
- select_by_visible_text()
- select_by_index()
- select_by_value()
- Keys.RETURN

## Installation

```bash
python -m pip install -U selenium
```

## How to Run
Run each Python file separately using the VS Code terminal.

## Objective
To learn how to interact with web form elements and verify user actions using Selenium WebDriver.
